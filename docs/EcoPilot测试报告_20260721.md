## 问题与建议

### 需关注
1. **授权签发流程**：`license_manager.py issue` 命令生成密钥后不会自动写入 license.key，需手动 `echo > ~/.ecopilot-home/license.key`。建议 issue 命令增加 `--save` 参数自动写入。
2. **/api/vault/files GET 返回 404**：可能需要 POST 方法或认证后的特殊处理，非阻塞问题。
3. **前端 browser_console 中 1 个 JS 错误**：onboarding 页 health check 解析偶尔报 `Cannot read properties of undefined (reading 'find')`，发生在后端未连接时，属预期错误处理。
