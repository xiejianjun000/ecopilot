|------|------|------|------|
| P-1 | `views/knowledge-graph.tsx` | O(n²) 斥力计算（line 75-86），大节点数卡顿 | 节点>100 即明显卡 |

## 十三、亮点（前端做得好的部分）

| 维度 | 亮点 |
|------|------|
| **状态管理** | Context + useReducer + HYDRATE 模式，SSR 安全，后端优先于 localStorage |
| **SSE 封装** | streamSSE async generator 封装规范，AbortController 中断实现正确 |
| **设计 token** | Tailwind v4 + OKLCH 色阶 + 语义变量，eco 色阶 50-900 完整定义 |
| **Modal 无障碍** | ui/modal.tsx 焦点陷阱+焦点恢复+ESC+body 锁定是最佳实践 |
| **监控 SDK** | monitor-sdk 批量缓冲+sendBeacon 卸载兼容设计专业 |
| **知识图谱** | 自实现 force simulation 无 d3 依赖，轻量 |
| **API 层** | lib/api.ts 统一封装 19 个方法，自动注入 authHeader + 监控上报 |
| **UI 原语** | ui/ 7 个组件职责单一、质量较高 |
