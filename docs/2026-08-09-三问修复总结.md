## 问题六：右侧栏 markdown 原始字符泄漏（`###` `***`）

### 现象

企业进化数据（L5）中的 AI 生成内容包含大量 markdown 格式标记（`### 标题`、`**加粗**`、`|表格|`、`---` 分割线等），在右侧栏 `line-clamp-1` 截断空间中直接显示为原始字符，严重影响可读性。

### 根因

`enterprise_evolution.jsonl` 中 124 条记录的知识内容由 AI 直接输出，保留了完整的 markdown 排版。前端渲染时仅在 EvolutionLayer 一处使用了 `stripMarkdown()` 清理，但 Next.js 缓存未清除，且其他层级（L1 SessionFrame / L2 合规记忆 / L3 工作日志 / L4 能力 / 通知中心）的内容渲染点均未做 markdown 清理。

### 修复方案

**1. 新增 `stripMarkdown()` 工具函数**（[utils.ts](file:///Users/mac/dev/ecopilot/desktop/frontend/lib/utils.ts#L17-L48)）：
- 14 个正则链式处理：标题标记 / 加粗斜体 / 链接 / 分割线 / 表格 / 行内代码 / HTML 标签 / 残留扫尾
- 支持跨行加粗匹配（`s` flag）
- 压缩多余空白行

**2. 右侧栏全层级覆盖**（[right-panel.tsx](file:///Users/mac/dev/ecopilot/desktop/frontend/components/right-panel.tsx)）：
- L1 SessionFrame：operations / findings / recommendations
- L2 合规记忆：`memories.content` 展示 + `SET_PREFILL_INPUT` 预填
- L3 工作日志：`diaryEntry.summary`
- L4 能力：`skill.description`
- L5 企业进化：`evolution.knowledge`（已有，本次确认生效）
- 通知中心：`memories.content` 截断摘要

### 效果验证

| 检查项 | 方法 | 结果 |
|--------|------|------|
| stripMarkdown 逻辑正确 | Python 模拟 124 条真实数据全量回归 | ✅ 0 残留 |

## 问题七：L4/L5 前端数据拉取初始化时序（已修复）

### 根因

两个独立 BUG：

| BUG | 表现 | 代码位置 |
|-----|------|----------|
| **静默吞错** | useEffect 中 4 个数据拉取的 `.catch(() => {})` 不输出任何日志 | store.ts `.catch` |
| **HYDRATE 并发覆盖** | 旧 reducer 对未传入字段设默认值 `|| []`，导致多次 dispatch 互相覆盖 | store.ts HYDRATE case |

### 修复方案（最终实施）

**1. `fetchWithRetry()` 通用重试函数**（[store.ts](file:///Users/mac/dev/ecopilot/desktop/frontend/lib/store.ts#L12-L37)）：
```typescript
export async function fetchWithRetry<T>(
  label: string,
  fetcher: () => Promise<T[]>,
  retries = 2,
  delayMs = 1000,
): Promise<T[]> {
  // 首次失败或空数组 → 等 1s 重试 1 次
  // 最终仍失败 → console.error + 返回空数组
}
```

**2. HYDRATE 非破坏性局部更新**（[store.ts](file:///Users/mac/dev/ecopilot/desktop/frontend/lib/store.ts#L471-L498)）：
```typescript
case 'HYDRATE': {
  const next = { ...state }
  if (p.selfLearningSkills !== undefined) next.selfLearningSkills = p.selfLearningSkills
  if (p.enterpriseEvolution !== undefined) next.enterpriseEvolution = p.enterpriseEvolution
  // ... 其他字段同理，仅更新传入的字段
  return next
}
```

**3. `ensureAuthToken` 错误日志**（[api.ts](file:///Users/mac/dev/ecopilot/desktop/frontend/lib/api.ts)）：
