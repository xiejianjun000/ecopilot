# EcoPilot 快捷卡片测试报告（输出长度评估）

| # | 卡片 | 字数 | 工具调用 | 评价 |
|---|------|------|---------|------|
| 1 | 完成排污许可证读取 | ~30字 | 1次 | ✅ 简洁，直接告知需注册 |
| 2 | 设置企业基本信息 | ~80字 | 0次 | ✅ 6项清单清晰，长度合理 |
| 3 | 查看生态环境法典核心条款 | — | — | ⚠️ 导航按钮，非对话触发 |

| 7 | ⚠️ 近期环保处罚案例 | ~500字+ | 2次 | ❌ 太长！5个案例×4项细节，冗余 |

## 问题诊断

**卡片7是主要问题**：5个处罚案例，每个案例4项（事实/处罚/双罚/教训），还在继续输出。内容本身有价值但密度过高。

**对比主动提问**（上一轮）：
- "高炉出铁场颗粒物25mg/m³"回复：包含2次结论+2张表格+法规引用+法典后果+4步建议+再次结论——约800字，严重冗余
- 重复输出同一结论2次
- "法律后果"部分用两次不同格式说同一件事

## 关于"内容输出太多"的根本原因

问题不在快捷卡片（1-6都很合理），而在：
1. **主动提问模式输出过长**：AI倾向于把结论、标准引用、法律后果、操作建议一次性全输出
2. **内容重复**：同一结论用不同格式说2-3次
3. **"处罚案例"类问题天然信息量大**，需要约束

## 建议

快捷卡片1-6保持现状，只需优化两处：

### 1. 卡片7"处罚案例"→ 限制为3个案例
```
当前：5个案例（还在继续）+ 每个4项细节
建议：最多3个案例，每个只列"处罚金额+法律依据"2项
```

### 2. 对话系统提示词 → 加长度约束
```
当前：无限制 → 800字回复
建议：添加"回复不超过300字。只给结论+1条标准引用+1个行动建议。不重复。"
```

### 3. 上排"引导卡片"vs下排"快捷指令"区分
- 上排（完成许可/设置信息/查看法典）→ 引导性，可以稍长
- 下排（📝📋🔍⚠️）→ 快捷指令，应该极简，250字封顶
