## 零、架构总览

EcoPilot 是构建在 **Hermes AI 引擎** 之上的生态环境合规应用。

```
┌──────────────────────────────────────────┐
│              EcoPilot (合规应用)           │
│  排污许可 · 执行报告 · 台账 · 监测 · 督察    │
├──────────────────────────────────────────┤
│            Hermes AI 引擎 (基座)           │
│  4层记忆 · 自学习 · GEPA进化 · 7Agent协作   │
├──────────────────────────────────────────┤
│      DeepSeek V4    │   Kimi Vision       │
│      (文本推理)      │   (视觉理解)         │
└──────────────────────────────────────────┘
```

| 层 | 职责 |
|---|---|
| **EcoPilot** | 许可证解析、排放标准对照、环保法规索引、督察整改流程、合规日历、台账管理 |
| **Hermes** | 记忆沉淀（500条）、自学习技能（13触发词）、7子代理路由、SKILL.md注入、企业知识进化 |
| **大模型** | DeepSeek V4（文本推理）+ Kimi Vision（文档OCR/图表解读） |

> EcoPilot = Hermes（AI 基座）+ 生态环境合规业务。Hermes 提供 AI 基础设施，EcoPilot 提供垂直领域业务逻辑。

## 八、快速部署

**Windows 用户**：下载 [EcoPilot-Setup-1.0.6.exe](https://github.com/xiejianjun000/ecopilot/releases/download/v1.0.6/EcoPilot-Setup-1.0.6.exe) 双击安装。

**新机器配置**：

1. 创建 `~/.ecopilot-home/.env`，填入 API Key：
   ```bash
   DEEPSEEK_API_KEY=sk-xxx
   KIMI_API_KEY=sk-xxx
   ```

2. 配置 MCP 知识库凭据（如需）：
   ```bash
   cp desktop/server/mcp_servers.local.example desktop/server/mcp_servers.local.json
   # 编辑 local.json，填入真实 IP 和 x-api-key
   ```

3. 获取机器指纹 → 申请授权码 → 输入激活。
