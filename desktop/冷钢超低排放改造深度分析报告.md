## 三、有组织排放改造技术路线

### 3.1 烧结机头——第一优先级（投资最大、效果最关键）

**当前状态**：颗粒物~25mg/m³，脱硫运行中（石灰石-石膏法/半干法之一），脱硝可能为SNCR或缺乏

**改造路径——颗粒物治理**：
```
现有布袋/电除尘 → 高效覆膜滤料布袋/电袋复合除尘器
颗粒物：25 → 10mg/m³
投资：单台烧结机 500-800万元
```

**改造路径——SO₂治理**：
```
现有湿法/半干法脱硫 → 增加喷淋层/提高液气比/增设托盘
或：半干法改湿法（效率更高但产生废水）
SO₂：目标≤35mg/m³
投资：单台升级 800-1200万元，如新建则 2000-3000万元
```

**改造路径——NOx治理（最大投入）**：
```
现有SNCR（如有）→ 中低温SCR脱硝（催化剂温度窗口180-250℃）
或：SNCR+SCR联合（利用现有SNCR，后置SCR补脱硝）
NOx：目标≤50mg/m³
催化剂：V₂O₅-WO₃/TiO₂蜂窝式，寿命3年
投资：单台烧结机SCR新建 2500-4000万元
```

**二噁英协同控制**：SCR催化剂对二噁英有60-80%协同脱除效果，加上活性炭喷射，可将二噁英从1.0→0.5ng以下。

**烧结机头综合改造投资估算（3台）**：

| 改造项目 | 单台投资 | 三台合计 |
|:---|:---:|:---:|
| 高效除尘升级 | 600万 | 1800万 |
| 脱硫系统升级 | 1000万 | 3000万 |
| SCR脱硝新建 | 3000万 | 9000万 |
| CEMS升级(超低量程) | 80万 | 240万 |
| **小计** | **4680万** | **1.40亿** |

### 3.2 高炉出铁场——第二优先级

**改造方案**：
```
出铁口全封闭罩 + 铁水沟加盖 + 撇渣器密闭
→ 脉冲布袋除尘器（覆膜滤料）→ 颗粒物≤10mg/m³
投资：5座高炉合计 1500-2500万元
```

**高炉热风炉**：如果使用高炉煤气（含硫低），SO₂通常达标。若使用混合煤气需评估。NOx可通过低氮燃烧器改造控制，单座投资200-400万。

### 3.3 转炉二次烟气

**改造方案**：
```
屋顶罩收集效率提升（加大罩口面积+提高风量）
→ 高效布袋除尘器
投资：3座转炉合计 800-1200万元
```

### 3.4 电炉、轧钢、石灰窑

| 工序 | 改造内容 | 投资估算 |

### 9.1 超低排放改造的碳效益

| 改造措施 | 电耗变化 | 碳排放影响 | 年减排量(估算) |
|:---|:---|:---|:---|
| SCR脱硝 | +15-25 kWh/t烧结矿 | **增加**排放 | +3000-5000 tCO₂/年 |
| 高效除尘 | +5-10 kWh/t | 轻微增加 | +1000-2000 tCO₂/年 |
| 脱硫升级 | +3-5 kWh/t | 轻微增加 | +600-1000 tCO₂/年 |
| 漏风治理 | **-8-12%** 主抽电耗 | **减少**排放 | -8000-12000 tCO₂/年 |
| 作业率提升(67→85%) | 产量增27%→单位电耗↓ | **减少**排放 | -15000-25000 tCO₂/年 |
| **净影响** | | **总体减排** | **-10000~20000 tCO₂/年** |

### 9.2 碳市场影响

钢铁行业已纳入全国碳市场。超低排放改造投入将影响：
- 配额基准年的排放强度 → 影响后续配额分配
- 能效提升（工序能耗53.37→50 kgce/t）直接降低碳排放
- 按吨钢碳排放~1.8 tCO₂、碳价80元/t计，年减排2万吨 → 碳资产价值**160万元/年**

### 9.3 政策红利
