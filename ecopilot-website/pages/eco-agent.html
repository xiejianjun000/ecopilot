eco Agent
五层循环驱动，持续自我进化

一套开源 AI 智能体系统。大多数 AI 智能体是一问一答——你唤醒它才工作；eco Agent 在无人唤醒时也能思考，在无人纠正时也能进化。

Python 3.10+ SQLite + FTS5 Docker GitHub Actions CI LLM 主用 Kimi

AGENT-01 · 架构核心

五层嵌套循环，
从一次回答到持续进化

每一层循环有自己的时间尺度：毫秒级的工具调用，秒级的任务编排，分钟级的后台心跳，天级的自我进化，以及贯穿始终的自愈。

L1 · 秒级

ReAct++

推理-行动循环增强版。置信度 < 0.6 自动暂停反思；工具失败自动回滚，不留脏状态。

L2 · 秒-分钟级

Task

多 Agent 并行执行，DAG 依赖图编排；循环依赖 5 秒自动破环，失败后最多 2 轮重规划。

L3 · 分钟-小时级演进中

Pulse

自适应后台心跳：数据同步 → 差异检测 → 规则触发 → 内存整理 → 主动建议。无人唤醒也在思考。

L4 · 天级演进中

Evolve

经验回放 → 差距分析 → 技能生成 → 记忆固化 → 版本快照，每次进化输出 evolution_report.md。

L5 · 贯穿始终

Heal

异常分类、指数退避重试、熔断、降级备用模型、检查点快照——系统带病也能优雅工作。

AGENT-02 · 能力矩阵

一套引擎，六种硬能力

三大产品共享的全部基座能力，每一行代码都可以在 GitHub 上审计。

动态自组织

10 秒将复杂任务分解为 5+ 子任务，最多调度 20 个并行 Agent 实例协同完成。

SOUL 人格体系

L1-L4 权限闸门：L4 外部写操作必须人工确认，全程 SM3 链式审计，可追溯、可问责。

技能自动生成

同一模式出现 3 次，60 秒自动生成新技能；A/B 测试验证，不满意可一键回滚。

Memory Tree

SQLite + FTS5 存储，BM25 + 语义混合检索，与 Obsidian 笔记库双向同步。

统一消息网关

已实现 Telegram / Discord / Slack / 飞书 / 企业微信 / 钉钉六大平台接入；51 个第三方连接器待命。

凭证安全

全部第三方凭证 Fernet 加密存储，密钥不出本机，最小权限按需授予。

AGENT-03 · 五种形态

从命令行到 Web 控制台

同一套内核，五种接入方式。插件热加载，写完即用，无需重启。

CLI

eco chat / eco run，开发者最顺手的第一入口。

eco server

管理 API 共 13 个端点，供任何系统远程调度。

Web 控制台

React 18 + Vite 构建，可视化任务、循环与技能状态。

Python SDK

三行代码把五层循环嵌入你自己的应用。

动态插件

插件热加载机制，能力边界由社区共同扩展。
